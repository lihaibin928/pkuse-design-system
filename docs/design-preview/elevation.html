层级与深度

Pkuse Design 采用 flat-first（扁平优先）。层级由边框和色调对比承担。阴影只出现在真正浮于上下文之上的表面。

阴影 Token 由 colorShadow 生成，同一名称可适应浅色/深色。核心档位：

Tertiary · boxShadowTertiary

轻抬起：0 1px 2px 0 rgba(0,0,0,0.05), 0 1px 6px -1px rgba(0,0,0,0.03), 0 2px 4px 0 rgba(0,0,0,0.03)

Popup · boxShadow / boxShadowSecondary

标准浮层：0 6px 16px 0 rgba(0,0,0,0.08), 0 3px 6px -4px rgba(0,0,0,0.12), 0 9px 28px 8px rgba(0,0,0,0.05)

  • Card（boxShadowCard）— 更紧的卡片抬起阴影，用于卡片需要与容器分离时。
  • Drawer / overflow（boxShadowDrawer*、boxShadowTabsOverflow*）— 贴边表面和滚动提示。
  • Popover arrow（boxShadowPopoverArrow）— 只用于 Tooltip / Popover 小三角。

动效

三种时长和一组 cubic-bezier，全部以 Token 暴露。不要任意挑选 transition-timing-function。需求对不上现有缓动时，用 motionEaseInOut 然后继续。

悬停色块查看 0.1s / 0.2s / 0.3s。缓动名称：motionEaseInOut、motionEaseOut、motionEaseIn、motionEaseOutBack、motionEaseOutCirc。
