结构规范

  • 侧栏导航：宽度 208px，可折叠至 48px；承载全部功能模块，支持两级菜单；选中项使用 #E6F4FF 浅底 + 主色文字。
  • 顶栏：高度 56px，左侧为品牌与面包屑，右侧为通知、帮助与用户信息；与内容区以边框分隔（层级来自描边而非阴影）。
  • 内容区：底色为 surface-layout #F5F5F5，页面内容以 bg-container #FFFFFF 卡片承载，内边距 24px。
  • qiankun 子应用：布局由主应用提供时，子应用只注册路由与页面，不重复实现侧栏与顶栏。
