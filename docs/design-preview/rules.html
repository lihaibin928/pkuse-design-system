对与错

做

用四个设计价值观当平局裁决。两种做法冲突时，更能让用户状态确定、更易读的那个胜出。

从 colors.surface、surface-container、surface-layout 读表面。它们对应三层模型。

找不到更具体 Token 时，组件级过渡用 motionDurationMid（0.2s）。

预设色板（blue 到 lime）只留给标签、图表和分类可视化。

每一个间隙、内边距和槽都通过间距刻度对齐 4px 网格。

不做

同一表面不要叠两个主色按钮。只留一个，其余降为 default。

不要硬编码 #FFFFFF 或 #FAFAFA。hex 是附带结果，角色才重要。

不要发明自定义 cubic-bezier。用已命名缓动。

不要在预设色板外铸造强调色给一次性 UI。若某屏看起来需要，多半该改布局。

不要在产品代码里用魔法数字。刻度缺一档时，该重看设计，而不是一像素覆盖。
