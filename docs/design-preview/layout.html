间距

所有间距对齐 4px 网格。六档间距（unit / xs / sm / md / lg / xl → 4 / 4 / 8 / 16 / 24 / 32）覆盖系统中每一个间隙、槽和内边距。Token 驱动的代码里不出现魔法数字。输入框水平 11px 内边距是网格确立前的历史值；一像素迁移会牵动海量已有屏幕，因此保留。

三层表面模型

永远不要在产品代码里写死 #FFF 或 #FAFAFA。读 Token。三层模型让暗色算法可以翻转表面阶梯而不拆布局。

1. bg-layout #F5F5F5 — 页面背景，包围并容纳其他一切。

2. bg-container #FFFFFF — 卡片、面板、表格、表单。大多数内容住在这里。

3. bg-elevated #FFFFFF

与 container 同 hex，靠阴影区分。用于对话框、下拉、气泡。
