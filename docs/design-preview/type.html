字体

基础字号是 14px，不是 16。企业控制台用信息密度换取额外易读空间——1440px 宽窗口需要同时放下侧栏、顶栏、八列表格和详情。14px 正文在这些栏宽下接近约 75 字符的扫视甜点。

字体栈按系统 UI 字体优先：-apple-system、BlinkMacSystemFont、Segoe UI、Roboto、Helvetica Neue、Arial、Noto Sans。代码字体：SFMono-Regular、Consolas、Liberation Mono、Menlo、Courier。

产品界面只用两个字重：400（正文、控件、菜单项、Tab 标签）和 600（fontWeightStrong —— 标题、表头、任何 title 级文字）。细体（100–300）、粗体（700+）和斜体不用于界面骨架。斜体只允许出现在长文本文档里。选中/激活态的强调来自颜色和描边（边框、下划线），不是字重。
