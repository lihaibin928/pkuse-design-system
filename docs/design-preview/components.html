Button · primary

每个屏幕唯一的主导操作。实心主色、白字、32px 高、6px 圆角。悬停变 #4096FF，按下变 #0958D9。同一决策面不要叠两个主按钮。

Button · default

次要操作。白底透明填充、深色文字、1px 描边。悬停文字与边框变为 #4096FF。

Input / Select

32px 高，与按钮对齐。细 1px 描边；焦点加粗主色边并带内发光。占位符用 on-surface-disabled。Select 在交互前看起来像 Input。

Card

工作马容器。白表面、8px 圆角、可选 boxShadowCard。内边距四边 24px；嵌套控件保持 16px 间隙。

卡片内容区，内边距 24px。

Modal

与 Card 同表面和圆角，但用次级阴影，居中叠在 rgba(0,0,0,0.45) 遮罩上。主体 padding 上下 20px、左右 24px。

Tag

小分类标签。4px 圆角、12px 字、低饱和粉彩来自预设色板。关键状态不要用 Tag，用 Alert 或 Badge。

默认 分类 · blue 分类 · 非状态主操作

Alert

语义反馈表面。成功/警告/错误/信息用浅语义底 + 正常文字色；状态由图标和底色传达，不用低对比的彩色正文。

✓成功：只用 success 绿提示结果，不要把整页做成绿色。
!警告：空数据用 Empty，保留查询区。
×错误：用 Result；401 和 403 分开。
i信息：加载中用 Spin，不要换一套绿色骨架屏。

Badge status

紧凑状态点。危急可用 error 填充，但在无障碍关键流程里圆点不能代替文字。
